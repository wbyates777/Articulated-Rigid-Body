Computes the joint space inertia matrix by using the Composite Rigid Body Algorithm (CRBA)

This function computes the joint space inertia matrix from a given model $m$ and the model state $qstate$.

Parameters
[in,out]mrigid body model
[in]qstatestate of the internal joints (positions, velocities, accelerations)
[out]Ha matrix where the result will be stored in
[in]update_kinematicswhether the kinematics should be updated (safer, but at a higher computational cost!)
Note
This function only evaluates the entries of H that are non-zero. Before calling this function ensure that all other values have been set to zero.

Computes forward dynamics with the Articulated Body algorithm (ABA)

This function computes the generalized accelerations $qddot$ from the given model $m$ and model state $qstate$. It does this by using the recursive Articulated Body Algorithm that runs in $O(n_{dof})$ with $n_{dof}$ being the number of joints.

Parameters
[in,out]mrigid body model
[in,out]qstatestate of the internal joints (positions, velocities, accelerations)
[in]f_extexternal forces acting on the body in base/world coordinates (optional, defaults to empty)
