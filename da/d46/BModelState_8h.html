Detailed Description

Holds the state of every joint in a model as vectors of scalars. 

  $$$$$$$$$$$$$$$$$$$$$
  $   BModelState.h   $
  $$$$$$$$$$$$$$$$$$$$$

date 29/11/2025

by W.B. Yates

The model state is:

  • std::vector<BScalar> m_q; // positions
  • std::vector<BScalar> m_qdot; // velocities
  • std::vector<BScalar> m_qddot; // accelerations
  • std::vector<BScalar> m_tau; // forces

The q, qdot, qddot, tau notation is taken from Featherstone's RBDA.

Note
initialising q to zero is safe because glm::mat3_cast(glm::quat(0,0,0,0)) is equal to B_IDENTITY_3x3
initialising q to one is not safe as glm::mat3_cast(glm::quat(1,1,1,1)) is not normalized and therefore not a rotation
