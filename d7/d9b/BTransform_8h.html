Detailed Description

A compact representation of spatial or Plücker Transforms (see Featherstone, RBDA, Section 2.8, page 20, and Appendix A3, page 245). 

 $$$$$$$$$$$$$$$$$$$$
 $   BTransform.h   $
 $$$$$$$$$$$$$$$$$$$$

date 20/02/2024

by W.B. Yates

Consider a tranform $X$ that maps points from a coordinate frame $A$ to a coordinate frame $B$

$$ B^X_A : A \rightarrow B. $$

The inverse $X^{-1}$ is defined by

$$ B^{X^{-1}}_A = A^X_B. $$

We require diﬀerent coordinate transformation matrices for motions and forces. For motion vectors $v \in M^6$,

$$ B^{X}_A : A \rightarrow B $$

For force vectors $v \in F^6$, the dual or 'star' version of the transform must be used

$$ B^{X^*}_A : A \rightarrow B $$

If the matrix $X$ performs a coordinate transformation on motion vectors, and $X^*$ performs the same transformation on force vectors, then the two are related by $X^* = X^{-T}$ (see Featherstone, RBDA, Section 2.6, eqn 2.13, page 18).

This class employs a compact representation of spatial transformations. Instead of using a full 6x6 matrix, the class only stores a 3x3 rotation matrix $E$ and a 3D translation vector $r$ to represent a spatial transformation. It also provides some efficient matrix operations such as matrix concatenation and transformation of spatial vectors.

The BTransform presented here has been tested against and matches the Eigen3 RBDL function:

SpatialMatrix toMatrix () const {
Matrix3d _Erx =
E * Matrix3d (
0., -r[2], r[1],
r[2], 0., -r[0],
-r[1], r[0], 0.
);
SpatialMatrix result;
result.block<3,3>(0,0) = E;
result.block<3,3>(0,3) = Matrix3d::Zero();
result.block<3,3>(3,0) = -_Erx;
result.block<3,3>(3,3) = E;
return result;
}

A spatial transform $X$ as a block 6x6 matrix has the form: 

     |     E      0  |
     | -rx * E    E  |

where rx = arb::cross(r).

The remaining transforms have analytic block definitions (which differ from the usual matrix definitions) for inverse and transpose: 

     X^{-1}  =  |    E^T      0  |
                | E^T * rx   E^T |

     X^T     =  | E^T    E^T * rx |
                |  0         E^T  |

     X^*  =     | E  -rx * E |
                | 0      E   |

where X^* = X^{-T} (see RBDA, page 22).

When transforming a spatial inertia $I$ by a spatial transform $X$ (see RBDA, eqn 2.66, page 34) 

       X.apply(I) returns I' = X^* I X^{-1} 
       X.applyTranspose(I) returns I' = X^T I X
Note
BMatrix3 E is a rotation; the transpose of a rotation E^T is also its inverse E^{-1}
BVector3 r is a translation; inverse translation is -r
As $(A * B)^T == (B^T * A^T)$ and $rx^T == -rx$ then $(-E * rx)^T == rx * E^T$ where the two negatives cancel out
